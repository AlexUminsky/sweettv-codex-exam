# Ручная загрузка

## Kaggle

1. Открой https://www.kaggle.com/competitions/sweettv-tv-program-recommender и войди в свой аккаунт. Прими Rules, если ещё не принял. Проверь отображение своего полного имени и Kaggle name.
2. Открой Submit Predictions и выбери **project/submission.csv** из локальной рабочей папки. В готовом GitHub bundle это тот же файл `submission.csv` в корне. Не выбирай исходный шаблон из data/extracted.
3. Дождись COMPLETE. Не меняй модель по полученному score. Открой подробности именно этой отправки и сделай настоящий скриншот, где читаются **private score**, статус и идентификатор/дата отправки. Public score и локальный MAP не заменяют private score.
4. Сохрани скриншот в `evidence/` вне github_upload. Отправь в этой же сессии его путь, submission reference/ссылку и подтверждение выбранного CSV. SHA-256 ожидаемого файла: `de641c8068e7d3f0bc93719a074a3b8ca1055ecb3b4836369e02635248af17e5`. Если реально отправлен другой файл, сообщи это; не подменяй доказательства.

## GitHub через браузер

1. В своём GitHub создай пустой репозиторий. Интеграция с Codex и токены не нужны.
2. Открой Add file → Upload files. Перетащи **содержимое** папки `github_upload/`, сохраняя папки `src`, `tests`, `results`, `logs`, `audit`. Файлов может быть больше лимита одной загрузки — загружай несколькими коммитами, не меняя содержимое.
3. Не загружай `data/`, `.venv/`, нативный JSONL, токены, скриншот аккаунта или всю папку исходной передачи. В подготовленном bundle этих файлов нет. Убедись, что `submission.csv` лежит в корне, README и код открываются.
4. Пришли URL репозитория. Ссылка должна быть доступна для чтения преподавателю; для открытого репозитория я смогу проверить файлы по URL.

## До сдачи курса

Нужны твои собственные расчёты и объяснения, ссылка репозитория и настоящий Kaggle private-score screenshot/reference. Пока их нет, PDF помечен WORKING и не является финальным отчётом. После проверки этих материалов отчёт будет завершён и все его страницы просмотрены.

В самом конце, после последнего ответа ассистента, выйди из Codex и выполни из корня передачи `python3 tools/session_audit.py copy`. Этот шаг ещё не следует выполнять во время текущей работы. В курс сдаются только окончательный PDF и неизменённый native JSONL. Если LMS не принимает `.jsonl` или журнал >10 MB, сначала уточни у преподавателя допустимый контейнер/расширение; не переименовывай, не преобразуй и не сжимай самовольно.
